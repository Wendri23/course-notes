Rules
  • Reading width — the note is max 68ch, 17px / 1.65; UI around it stays 13–15px
  • Links — underlined (1px, control gray) in text, breadcrumb, rail, tables; plain in A–Z lists, rows, chips; hover = 2px vermillon
  • Focus — every interactive element: 2px vermillon outline, 2px offset, keyboard only
  • Progress wording — “opened” (a note was opened at least once), never “read”
  • Status — frontmatter status is plain meta text (“Draft · updated …”), never a chip
  • Back — always a real parent (breadcrumb / back link), never browser history
  • Graph — static preview in the rail; interactive in Quartz, with an expand button (top right) for the full graph
  • Theme — follows the device (prefers-color-scheme) until the switch is used; Quartz stores it as saved-theme
Quartz implementation

From these tokens to Quartz

Quartz takes a fixed 9-color palette in quartz.config.ts (one set per mode). Its default uses secondary for every link, so putting vermillon there would color the whole site. Instead: secondary = ink, tertiary = vermillon, and a few custom.scss rules for what the palette can't express.

quartz/styles/custom.scss 
// quartz/styles/custom.scss — what the palette can't express
:root { --accent: #E34234; --ctl: #d4d4d4; }
:root[saved-theme="dark"] { --accent: #FF6A4D; --ctl: #3d3d3d; }

// links are ink; the accent only shows on hover
a.internal { background: none; text-decoration: underline;
  text-decoration-color: var(--lightgray); text-underline-offset: 3px; }
a:hover { color: var(--dark); text-decoration-color: var(--accent);
  text-decoration-thickness: 2px; }

// titles: Newsreader 500, 48px
h1.article-title { font-weight: 500; font-size: 48px;
  letter-spacing: -.015em; line-height: 1.1; }

// accent, used sparingly
.progress > i, .continue-dot { background: var(--accent); }
.toc a.in-view { border-left: 2px solid var(--accent); }
input:focus, select:focus { outline: none; border-color: var(--accent); }

// 1px lines only, no radius except chips
.search > .search-button, input, select { border: 1px solid var(--ctl);
  border-radius: 0; }
Accent budget per page
  • Progress bar fill (Home table, Course, Chapter)
  • Dot before the last opened note (Home)
  • Active heading in “On this page” (Chapter, Concept)
  • Hover underline & chip border · keyboard focus outline
  • Active node in the graph (Quartz tertiary)

Never: text color, backgrounds, headings, buttons, read marks.
