## 1961–1972 : early packet switching
- 1961 Kleinrock : queueing theory shows packet switching is effective
- 1964 Baran : packet switching in military networks
- 1967 ARPAnet conceived (ARPA) → 1969 first node
- 1972 : public demo, NCP (first host-host protocol), first e-mail, 15 nodes

## 1972–1980 : internetworking
- ALOHAnet (Hawaii), 1973 Ethernet (Metcalfe), proprietary archis (DECnet, SNA)
- 1974 **Cerf & Kahn** : architecture to interconnect networks
	- minimalism, autonomy (no internal change to interconnect)
	- [[Best Effort]] service model
	- stateless routers
	- decentralised control
	- → still today's Internet architecture
- 1979 : 200 nodes

## 1980–1990 : proliferation
- 1982 SMTP, 1983 **TCP/IP** deployed + DNS, 1985 FTP, 1988 TCP congestion control
- New national networks (NSFnet, Minitel...) → 100 000 hosts

## 1990–2000 : commercialisation, the Web
- ARPAnet decommissioned, 1991 commercial use of NSFnet allowed
- **Web** : HTML, HTTP (Berners-Lee), 1994 Mosaic / Netscape
- Killer apps : instant messaging, P2P (Napster), security becomes central

## 21st century
- GAFA, BATX, apps, cloud computing, "Uberization"
- [[Software Defined Networking|SDN]], [[Network Function Virtualisation|NFV]]
