**UML usage styles** : UML is used in many **contexts** (problem or solution) and with three **styles** (Fowler) : **sketch, blueprint, programming**.

## Contexts
- **problem** : business modelling, requirements analysis (see [[IS Analysis]])
- **solution** : software design, data modelling

## Styles (Fowler)

| Style | Purpose | Completeness |
|---|---|---|
| **Sketch** | communicate and explore ideas | partial, informal |
| **Blueprint** | detailed spec handed to developers or code generators | complete enough to build from |
| **Programming** | the model *is* the program (executable UML) | complete and executable |

The descriptions of each style are general knowledge ; the slide only names them.
