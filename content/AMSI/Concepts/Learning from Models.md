**Learning from models** : four ways to get knowledge out of a model before building the real system : **build, inspect, formally analyse, experiment** (Selic, 2003).

| Way | How | Notes |
|---|---|---|
| **Build** | write the model | the questions raised remain valid for building the actual system |
| **Inspect** | mental execution | cheap, relies on the reader |
| **Formally analyse** | proofs, model checking | requires **formal** languages ; reliable in theory ; costly? ; verification ≠ validation |
| **Experiment** | execution, simulation, animation | gives a concrete *grasp* of the behaviour |

- formal analysis is how a model becomes **predictive** (see [[Model Qualities]])
- **verification** = is the system built right? **validation** = is it the right system? (see [[IS Analysis]])
