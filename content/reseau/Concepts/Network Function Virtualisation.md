Network functions (firewall, NAT, load balancer...) run as **software** on generic servers / virtual machines, instead of dedicated hardware boxes.

- Complementary to [[Software Defined Networking|SDN]] : SDN separates control from forwarding, NFV virtualises the functions themselves
- Part of the "road ahead" against Internet ossification
